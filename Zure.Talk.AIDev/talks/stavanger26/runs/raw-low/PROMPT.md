Build the game described in idea.md as a small real-time multiplayer browser game.
Two players must be able to join from two browsers, see each other's moves, and see
when the other player disconnects. State lives in server memory only.

Use whatever workflow your installed skills or tools provide. Follow AGENTS.md.
Prove it works with Playwright tests that play it as two players.
You have about 25 minutes. Say DONE when `npm run test:e2e` passes.
